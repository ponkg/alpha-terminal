ALPHA / DOCUMENTATION 01.0

Field Manual.

A practical guide to Alpha's Solana narrative intelligence terminal: how to explore the market, read the feed, inspect tokens and understand the data behind the interface.

PRODUCT GUIDETERMINAL WORKFLOWDATA TRANSPARENCY
Alpha is a research interface. It does not execute trades, provide personalized financial advice or guarantee that a token is safe or profitable.
01 / START HERE

What is Alpha?

Alpha organizes parts of the Solana market-research process into one terminal. The current experience combines narrative-oriented token discovery, a categorized news feed, a token scanner and keyboard-first navigation.

02 / ACCESS

Waitlist, invitation and sign-in

The public waitlist and the private beta account are separate steps.

  1. Submit your X handle through the public waitlist form.
  2. The Alpha team reviews waitlist entries and may send a beta invitation to an email address.
  3. Use the invited email address to sign in with the password you set or an available sign-in link.
  4. Access to member features is checked by Alpha's backend.

You do not need to connect a wallet to join the public waitlist. Never share a wallet seed phrase or private key with anyone claiming to represent Alpha.

03 / TERMINAL TOOLS

Market Tracker

The Tracker combines a market-token directory with configured narrative categories and detected entity groups. Select a category in the left rail to filter the token list. Select ALL TOKENS to return to the full directory.

Explore a category

  1. Open the Tracker using Alt + 1.
  2. Choose a folder under Market Categories or Detected Entities.
  3. Use the search field to filter by ticker, token name or mint address.
  4. Inspect the token's detection details to see which configured label matched and the available reason.
  5. Select a token row to open its chart and token details.

How classification works

Current narrative grouping uses configured keyword and entity matching against available token metadata, including symbol, name and pool name. It is a rule-based categorization layer, not an AI judgment about a token's meaning or a guarantee that the token genuinely belongs to a theme.

A token can match more than one category. A token with insufficient matching metadata may appear under Other / Unclassified.

04 / TERMINAL TOOLS

News Feed

The News Feed aggregates a selected set of RSS sources, normalizes article details and displays them in a categorized terminal layout.

Using the feed

  • Choose a category in the feed index.
  • Search headlines, topics or people using the search input.
  • Review the publisher, publication details and available summary.
  • Open the headline to read the original article at its publisher.

Entity tags are generated from configured name and keyword matching against article text. A matching tag is a contextual clue, not proof that the article caused a token's price movement.

The current News Feed uses selected RSS sources. It is not a live X/Twitter feed and should not be described as one.
05 / TERMINAL TOOLS

Coin Scanner

The Scanner gathers available public information about a token and its associated pool. Enter a Solana mint address where possible. A ticker can be ambiguous because different tokens can share the same symbol.

Signals shown by the Scanner

CHECKWHAT IT DESCRIBES
LiquidityReported liquidity for the selected market pool.
Pool ageHow long the selected pool has existed, where the data is available.
HoldersAvailable holder-distribution and concentration information.
AuthorityAvailable mint and freeze authority information.
ActivityAvailable trading and transaction activity signals.
ProfileAvailable public token-profile and social metadata.

Check results depend on third-party provider coverage. An unavailable field is unknown; it should not be interpreted as a clean result. A warning is a research signal, not a complete audit.

08 / TRANSPARENCY

Timeframes and derived measurements

Alpha uses native provider intervals where they are available. In the current Tracker feed, Jupiter supplies native 5-minute, 1-hour and 24-hour ranking data. The 10-minute and 30-minute changes are derived from price snapshots sampled from the 5-minute feed.

These sampled measurements need sufficient history to calculate a comparison. The server keeps a rolling, in-memory history, so a service restart clears the collected samples. An unavailable derived measurement should not be read as zero movement.

09 / TRANSPARENCY

Known limitations

  • Third-party market APIs can rate-limit, fail or return incomplete information.
  • Cached data may be older than a fresh provider response.
  • Token metadata and narrative classifications can be incomplete or incorrect.
  • RSS coverage depends on the availability and publication behavior of selected sources.
  • Scanner checks cannot prove that a token is safe or identify every malicious behavior.
  • Derived timeframes depend on the sample history available to the running service.

Always verify the token mint address, pool, liquidity and source data independently. Never trade solely because an item appears in Alpha.

10 / REFERENCE

Frequently asked questions

Does Alpha connect to my wallet?

The current research workflow does not require a wallet connection. Do not provide seed phrases or private keys.

Does Alpha execute trades?

No. Alpha is a research terminal and does not execute trades.

Are narrative matches AI-generated?

Current token labels use configured keyword and entity rules. They are not an AI guarantee or a complete semantic classification.

Why is some data missing?

The underlying provider may not supply the field, the selected token or pool may not have coverage, or a provider request may have failed or been rate-limited.

Does Alpha provide financial advice?

No. Alpha provides informational research tools only. All decisions and verification remain the user's responsibility.
